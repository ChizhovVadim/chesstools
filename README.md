# chesstools
Библиотека позволяет на языке golang:
- работать с шахматными uci движками
- работать с шахматными партиями в формате PGN


В качестве примера реализованы:
- игра с uci движком в консоли. Используются юникодные символы шахматных фигур
- проведение матча между двумя uci движками


Поддерживаются различные ОС: Mac, Linux, Win.


Пример запуска:
```
$ go run ./cmd/utils gui -engine <name>
```
